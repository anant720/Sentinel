## Technical Stack

- **Framework:** React 18 + Vite
- **Data Fetching:** TanStack React Query (`v5`)
- **State Management:** Zustand (with persistence for auth)
- **Styling:** Tailwind CSS + Lucide Icons
- **Real-time:** WebSocket connections to matching Sentinel Core WS endpoint

## Getting Started

1. Set up the `sentinel-core` backend first.
2. Run `npm install`
3. Check the `.env.local` to ensure `VITE_API_URL` points to your backend.
4. Run `npm run dev` and navigate to `http://localhost:5173`.
